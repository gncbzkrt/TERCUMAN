TERCÜMAN v0.6.0 - TELEFONDAN GITHUB İLE APK

1) Bu paketin içindeki DOSYALARI mevcut TERCUMAN GitHub reposunun köküne kopyala.
2) Termux'ta repo klasörüne gir.
3) `git add -A`
4) `git commit -m "TERCUMAN v0.6.0"`
5) `git push`
6) GitHub Actions -> `TERCUMAN APK` çalışır.
7) Yeşil tamamlanınca Artifacts bölümünden `TERCUMAN-v0.6.0-APK` paketini indir.
8) Paket içindeki `TERCUMAN-v0.6.0-debug.apk` dosyasını kur.

İLK AÇILIŞ
- Mikrofon iznini ver.
- `AI MODELLERİNİ HAZIRLA`ya bas.
- Butonun hemen altındaki küçük ilerleme göstergesinde `1/2`, `2/2` ve sonunda `AI HAZIR ✓` görünür.
- Sonra `DIŞ SES` veya `TELEFON SESİ` seç.
- Sesli çeviri için Ses ve Ton seç.

NOT
Bazı uygulamalar kendi sesinin yakalanmasına Android seviyesinde izin vermez. Sessiz akışta TERCÜMAN bunu açıkça bildirir.
