# TERCUMAN v1.4.0 build fix

GitHub Actions v1.4.0 failed before compilation because Kotlin 2.3.0 rejects the legacy `kotlinOptions { jvmTarget = "17" }` DSL.

Fix: removed the legacy `kotlinOptions` block. The project already uses the supported Kotlin compilerOptions DSL:

`kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_17) } }`

No application feature code is changed by this build-only fix.
