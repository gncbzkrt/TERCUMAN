# TERCÜMAN v1.3.0 — AI Conversation Engine

This package is based on TERCÜMAN v1.2.0 and adds a local AI sentence-boundary engine.

## What changed

- Local Qwen3-0.6B INT4 no-think LiteRT-LM model.
- The model is downloaded once on first "AI HAZIRLA" and stored under app-local model storage.
- Streaming ASR no longer decides linguistic sentence boundaries.
- Sherpa endpoint events only trigger the AI decision.
- AI returns COMMIT/WAIT-style decisions for human-sized meaning units.
- Translation runs only after AI commits a stable sentence.
- Speaker diarization remains independent and non-blocking.
- Conversation history remains ordered.
- Existing microphone and Android playback-capture paths remain.
- Existing TTS and UI remain.
- AI failure falls back to the lightweight local rule gate.
- Version: 1.3.0 / versionCode 23.

## Build

GitHub Actions remains the normal build path. The workflow produces:

TERCUMAN-v1.3.0-APK / TERCUMAN-v1.3.0-debug.apk

Local Termux builds still require a configured Android SDK.

## Important

This version does not claim biometric speaker identity. Speaker A/B labels still come from the local diarization engine; the language AI only handles linguistic segmentation.

The local LLM is deliberately not used as the translator. ML Kit remains the translation engine.
