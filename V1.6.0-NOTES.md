# TERCÜMAN v1.6.0 — TRUE BIDIRECTIONAL PACKAGE

- Multilingual local streaming ASR: Nemotron 3.5 ASR 0.6B, 320 ms chunk model.
- Auto language mode per stream.
- Turkish ↔ foreign-language route selection. The first detected foreign language becomes the default return language for Turkish replies.
- Local ML Kit language identification + on-device ML Kit translation.
- AI sentence-boundary controller made language-neutral.
- v1.5 fast translation architecture retained: translation never waits for the AI decision.
- Conversation generation/revision guards retained.
- Source history remains newest at bottom; translation history remains newest at top.
- Phone playback capture and microphone modes retained.

## Deliberate non-goals

- No cloud translation API, subscription, API key, or per-minute billing.
- No claim of universal language support: the streaming ASR checkpoint provides a defined multilingual locale set; unsupported languages must be added through a compatible local model later.
- Speaker diarization remains the existing local engine; v1.6 improves the conversation route but does not pretend speaker ID is perfect.

## Model choice

The 320 ms multilingual Nemotron checkpoint is selected to keep the new auto-language path responsive while remaining a single local streaming model. The model officially supports Turkish plus English, Spanish, French, Italian, Portuguese, Dutch, German, Russian, Arabic, Hindi, Japanese, Korean, Vietnamese and Ukrainian, with additional broad-coverage locales.
